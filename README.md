# Campus Resource Sharing Platform

This workspace contains a browser-only resource sharing and tracking UI.

## Features

- Sidebar navigation for Dashboard, Resources, Request, Approvals, Returns, and History.
- Top navbar actions for notifications, login, and dark mode.
- Request workflow with timing, approval tracking, return tracking, and history.
- Resource cards that show active timing windows.
- Local storage persistence for requests, notifications, and theme state.

## Files

- `List-item.Html` - main UI shell and page sections.
- `style.css` - responsive styling and dark mode variables.
- `script.js` - request logic, notifications, theme toggling, and login state.

## Usage

1. Open `List-item.Html` in a browser.
2. Use the sidebar to switch between dashboard and tracking pages.
3. Create requests from the Request page.
4. Approve or return requests from the tracking sections.

## Notes

- The login button is a local UI state demo, not real authentication.
- No backend is required for this version.
